# Support

## Usage help

For installation, configuration, and usage questions:

1. Review the [README](README.md), especially installation, configuration, and troubleshooting.
2. Search existing [GitHub Discussions](https://github.com/scrunchds/Command-Center/discussions) and issues.
3. Start a discussion in the appropriate category if the question remains unanswered.

## Bugs and feature requests

Use the repository's issue forms for reproducible bug reports and well-defined feature requests. Issues are not a guaranteed support channel, and response times may vary.

Before sharing diagnostics, remove API keys, vault content, personal information, local filesystem paths, private hostnames/IPs, and other sensitive data.

## Security and conduct reports

Do not file security vulnerabilities or sensitive conduct reports publicly. Follow [SECURITY.md](SECURITY.md) or [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) to report them privately.

## Scope

Command Center is maintained as an open-source project. Community help is best-effort; individualized vault design, model-provider support, and third-party service availability are outside the project's support guarantee.
